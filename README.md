# nvim-practice

Deliberate practice for mastering Neovim through structured lessons and exercises.

## Goals

- Learn Neovim by practicing daily
- Build muscle memory through repetition
- Master motions, operators, text objects, registers, macros, and command mode
- Keep the plugin lightweight and dependency-free

## Philosophy

Practice first.

The plugin is designed around focused, repeatable exercises rather than tutorials.
