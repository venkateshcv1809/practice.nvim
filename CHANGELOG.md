# Changelog

Plugin versions follow [Semantic Versioning](https://semver.org/). Git tags are
`vMAJOR.MINOR.PATCH`. While the version is `0.y.z`, commands, `setup()` keys, and
lesson IDs may still change.

Content packs keep a separate JSON `schema_version`. That number is not this
plugin release.

## [0.1.0] - 2026-11-02

First tagged developer release.

- Neovim 0.9+ plugin with a landing menu, navigation game, twelve editor
  lessons, and native-tab typing.
- Optional Prosetta adapter. Terminal practice is not included.
- In-memory progress only; it does not survive restart.
